# Presentation artwork

`bezel.png` is the custom presentation frame supplied and approved by the project owner for Meteos. It was restored at their request on 2026-11-14. It is not extracted from the JAR and is not needed to execute the game.

SHA-256: `1a06bfa0a898a50843af4cbf241eb28394dce5ebd6b38c552eefdcd49b9e6c9d`.

The frame contains game branding/characters; those underlying marks remain with their respective owners. The project's code license does not assert ownership of those marks. Other game projects must supply their own authorized presentation artwork; do not reuse the Meteos frame automatically.
